# <조직명> 정본 — 여기서 일하는 AI 에게

> 이 파일은 **진입점**이다. 이 폴더(또는 하위 폴더)에서 AI 클라이언트를 열면 자동으로 읽힌다.
> 특정 컴퓨터의 경로를 적지 않는다 — 마운트 경로는 사람마다 다르고, **지금 열려 있는 이 폴더가 그 경로다.**

## 0. 처음이면

개인 지침에 `[조직 공통]` 표식이 없으면 `50_도구상자/00_온보딩/온보딩.md` 를 읽고 그 절차를 따른다.
**사람에게 OS·경로·드라이브 문자를 묻지 않는다 — 직접 확인한다.**

## 1. 매 세션 시작할 때

1. `50_도구상자/00_규범/공통규약.md` 를 읽는다
2. `_시스템/상태/` 의 신선도 지표를 읽는다. 기준보다 오래됐으면
   **「내가 보는 자료가 N시간 뒤처졌습니다」 하고 사람에게 알린 뒤 멈춘다.** 낡은 자료로 결론내지 않는다
3. 내 과제 폴더의 `CLAUDE.md`(없으면 `_README.md`)를 읽는다
4. 파일을 찾을 때는 `_시스템/색인/` 의 목록을 검색한다. 폴더를 걸어 다니지 않는다

## 2. 이 폴더의 구조

| 폴더 | 무엇 | 쓰는 사람 |
|---|---|---|
| `00_공통/` | 조직 · 일정 · **온톨로지**(사람·조직·고객·과제) | 사람 (일정은 자동) |
| `<부서>/10_과제/` | **과제별 정본** — 제안 · 수행중 · 실주 · 종료·정산 · 인증 | 담당자 |
| `<부서>/00_부서정본/` | 주간보고 등 | 사람 |
| `<부서>/40_커뮤니케이션/` | 메일 · 메신저 · **회의록** (메일·메신저는 자동) | 회의록만 사람 |
| `<부서>/50_대시보드/` | 대시보드 (자동) — 열어 보기만 | 자동화 |

| `50_도구상자/` | **규범 · 온보딩 · 스킬** | 관리자 |
| `_시스템/` | 색인 · 상태 · 보안 — **기계 전용** | 자동화 |

## 3. 「없다」고 말하기 전에

공통규약의 탐색 계약을 따른다. 요약: **신선도 → 용어 확장 → 이름 검색 → 내용 검색 → 구조 →
여섯 줄 보고.** 「미발견」은 그 보고의 마지막 줄로만 쓴다.

## 4. 쓰기

- **내 과제 폴더에 쓴다.**
- 자동화 구역(`_시스템/` · `50_대시보드/` · 메일 · 메신저 · 캘린더)은 **읽기만.**
  고치려면 내 폴더에 복사해서.
- 남의 파일을 지우거나 옮기지 않는다. 확실하지 않으면 먼저 묻는다.
- 구역표: `50_도구상자/00_규범/쓰기구역표.md`
