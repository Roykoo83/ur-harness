# 쓰기 구역표

**경로마다 쓰는 주체는 하나다.** 이 표가 그것을 정한다.

## 기계 구역 — 자동화만 쓴다

| 경로 | 무엇 |
|---|---|
| `_시스템/` | 색인 · 상태 · 보안 원장 |
| `<부서>/40_커뮤니케이션/메일/` | 승격된 업무 메일 |
| `<부서>/40_커뮤니케이션/메신저/` | 아카이빙된 대화 |
| `00_공통/20_일정/` | 캘린더 |
| `<부서>/50_대시보드/` | 생성된 대시보드 |
| `<부서>/00_부서정본/주간보고_초안/` | 자동 초안 |

사람은 **읽기만** 한다. 고치려면 자기 폴더에 복사해서 고친다.

## 사람 구역 — 사람(의 AI)이 쓴다

| 경로 | 무엇 |
|---|---|
| `<부서>/10_과제/**` | 과제 산출물 · 작업로그 |
| `<부서>/40_커뮤니케이션/회의록/` | 확정 회의록 |
| `<부서>/00_부서정본/` (초안 폴더 제외) | 부서 문서 |
| `00_공통/50_온톨로지/` | 사람 · 조직 · 고객 · 과제 (자동 갱신분은 예외) |
| `30_시스템/` · `50_도구상자/` | 설계 · 규범 · 스킬 |

자동화가 이 구역에 쓰려 하면 **거부한다.** 예외가 필요하면 그 사유를 코드에 남긴다.

## 어느 쪽도 아닌 것

| 경로 | |
|---|---|
| `_로컬/` | 외부에 내지 않는 원본. 동기화 대상이 아니다 |
| 과제 폴더의 `_old/` | 지난 판. 지우지 않고 남겨 둔다 |

## 이 표를 어기면

실제로 난 사고 둘:

- 자동화가 동기화 명령으로 **구성원이 올린 파일 7건을 지웠다** — "기계 구역이니 전부 기계 것"
  이라고 가정한 것이 틀렸다. 기계 구역은 *누가 써도 되는가*이지 *그 폴더가 전부 기계 것*이 아니다
- 같은 파일을 두 경로(API·마운트)로 쓰다가 **원문이 사라졌다**
