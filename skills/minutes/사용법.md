# 회의록 만들기 : 사용법

## 한 줄

회의가 끝나면 `/minutes` 라고 치거나 "회의록 만들어줘"라고 말하면 됩니다.

---

## 두 가지 경로

| 어떤 회의였나 | 무엇을 준비하나 | 걸리는 시간 |
|---|---|---|
| **온라인** (Zoom, Google Meet) | 없습니다. Fathom이 이미 녹화했습니다 | 전사는 회의 직후 자동 완료 |
| **대면** (녹음기, 휴대폰) | 음성 파일 | 약 1분 (외부 전송 안 하면 녹음 길이의 2배) |

---

## 온라인 회의를 처음 쓴다면

Fathom을 한 번만 설정하면 그 뒤로는 신경 쓸 것이 없습니다.

1. `fathom.video` 에서 회원가입합니다. 무료 플랜으로 충분합니다
2. Zoom 또는 Google Meet 계정을 연결합니다
3. **끝입니다.** 다음 회의부터 Fathom이 알아서 참석해 녹화하고 전사합니다

참석자에게는 녹화 중이라는 안내가 뜹니다. 몰래 하는 것이 아닙니다.

---

## 대면 회의를 녹음했다면

휴대폰 녹음기로 충분합니다. 파일 형식은 신경 쓰지 않아도 됩니다.

Claude Code 창에 **파일을 끌어다 놓으면** 경로가 자동으로 입력됩니다.
그 상태로 "이거 회의록 만들어줘"라고 하면 됩니다.

전사는 **Groq 서버로 보내서** 합니다. 1시간 회의가 약 1분이면 끝납니다.
실행하면 "전송해도 되겠나" 하고 한 번 묻습니다.

**외부로 내보내면 안 되는 회의는 알려주세요.** 외부 인사 발언, 환자 정보,
미공개 과제 내용이 있는 회의는 이 컴퓨터 안에서만 처리하는 방식으로 돌립니다.
대신 녹음 길이의 약 2배가 걸립니다.

첫 실행은 오래 걸립니다. 전사 모델 2.9GB를 내려받기 때문입니다.
설치할 때 샘플을 한 번 돌렸다면 이미 받아둔 상태라 바로 시작합니다. 그다음부터는 빠릅니다.

---

## 그다음에 일어나는 일

전사만으로는 회의록이 되지 않습니다. **자동 전사는 이름과 숫자를 틀립니다.**

실제로 겪은 것들입니다.

| 전사가 들은 것 | 실제 |
|---|---|
| 고양이 AI | 고영향 AI |
| 뉴드라이브 | U드라이브 |
| 7곡 | 칠곡 |
| SST | SSOT |

그래서 전사한 뒤에 회사 정본과 대조합니다. 사람 이름은 온톨로지에서, 과제명은 과제 폴더에서,
숫자는 원장에서 확인합니다. **전사보다 문서를 믿습니다.**

### 모델을 작은 것으로 바꾸지 마세요

2026-09-14에 같은 음성을 두 모델로 돌려 비교했습니다.
읽힌 문장은 "오늘 회의에서는 고영향 AI 예비심사 일정과 칠곡 과제 중간 보고를 다뤘습니다.
{{MEMBER_B}} 리더가 운영 대시보드를 보고했습니다." 입니다.

| 모델 | 틀린 곳 |
|---|---|
| tiny | 고영향 **에의 에의 에비심사** · 칠곡 >> **7국** · 보고 >> **포고** · 다뤘습니다 >> **타렸습니다** · {{MEMBER_B}} >> **김소년** |
| medium | 칠곡 >> **7곡** · 과제 >> **화제** · 대시보드 >> **대시포드** (사람 이름과 과제 핵심어는 맞음) |

작은 모델은 사람 이름까지 무너집니다. 기본값 `large-v3` 를 그대로 쓰세요.
medium 조차 과제명(칠곡)과 일반 단어(과제·대시보드)를 틀립니다.
**어떤 모델을 써도 교정 단계는 건너뛸 수 없습니다.**

---

## 당신이 할 일은 한 번입니다

교정이 끝나면 초안을 보여드립니다. 그때 세 가지를 함께 드립니다.

1. **회의록 초안**
2. **고친 것 목록** : 전사가 뭘 잘못 들었고 뭐로 바꿨는지
3. **모르겠는 것** : 확정할 수 없어 빈칸으로 둔 항목들

세 번째가 중요합니다. 확실하지 않은 것을 그럴듯하게 채우지 않습니다.
문맥만 보여드리니 **아는 것만 채워주시면** 됩니다.

고쳐주신 내용이 정본이 됩니다. 같은 실수가 반복되면 규칙으로 만들어 다음부터 자동으로 막습니다.

---

## 완성되면 어디로 가나

확정본과 교정기록이 정본 폴더에 올라갑니다. (전사 원문은 보안 등급 판정 후)

```
{{SSOT_DRIVE}} / {{DEPT_ROOT}} / 40_커뮤니케이션 / 회의록 /
```

전사 원문은 보안 등급을 판정한 뒤 처리합니다. 작업 폴더의 중간 파일은 올리지 않습니다.
회의록은 회의의 기록이지 작성 과정의 기록이 아니기 때문입니다.

## 자주 묻는 것

**녹음 파일이 외부로 나가나요**
아니요. 대면 회의 전사는 전부 이 컴퓨터 안에서 처리됩니다.
온라인 회의는 Fathom 서비스를 쓰므로 그쪽 서버를 거칩니다.

**시간이 얼마나 걸리나요**
온라인은 이미 전사가 되어 있어 교정만 하면 몇 분입니다.
**기본은 1분 안팎입니다.** 실측으로 7분 통화 3초, 45분 회의 13초였습니다.

외부로 내보내지 않는 방식을 쓰면 **녹음 길이의 약 2배**입니다.
1시간 회의에 약 2시간이고, 이때는 진행이 멈춘 것처럼 보여도 고장이 아닙니다.
긴 회의는 퇴근 전에 걸어두고 다음 날 받는 편이 낫습니다.

**전사가 너무 틀리게 나왔어요**
녹음 품질 문제일 가능성이 큽니다. 마이크가 멀거나 여러 명이 동시에 말하면 정확도가 떨어집니다.
그래도 교정 단계에서 상당 부분 잡힙니다. 심하면 알려주세요.

**누가 말했는지 구분되나요**
Fathom 전사에서 화자 구분이 안 되는 경우가 있습니다.
그럴 때는 발언을 특정인에게 돌리지 않고, 명백한 경우만 이름을 답니다.

**Fathom 에 전사가 없어요**
봇이 회의에 못 들어온 경우입니다. 남이 연 방이면 호스트가 대기실에서 승인해야 들어옵니다.
다음부터는 호스트에게 미리 부탁하거나, `OBS_회의녹화.md` 를 따라 직접 녹화하세요.

**설치가 안 돼요**
`설치.md` 파일 내용을 복사해서 Claude Code 창에 붙여넣으세요.
OS와 경로를 알아서 찾아 설치합니다. 그래도 안 되면 연구기획사업부에 알려주세요.
