# 회의록 스킬 설치   Claude Code 에게 주는 지시문

## 사람이 할 일 (10초)

**이 파일 내용을 전부 복사해서 Claude Code 대화창에 붙여넣으세요.** 그것으로 끝입니다.
OS도 경로도 파이썬 설치 여부도 몰라도 됩니다. Claude Code 가 직접 확인하고 처리합니다.

---

## Claude Code 가 할 일

아래를 순서대로 실행한다. **사람에게 OS나 경로를 묻지 않는다.** 직접 확인한다.
설치 범위를 벗어나는 변경은 하지 않는다.

### 1단계. OS 와 파이썬

**macOS** (터미널)

```bash
uname -s; echo $HOME
python3 -V || python -V
ls ~/.claude/skills/ 2>/dev/null
```

**Windows** (PowerShell)

```powershell
$env:USERPROFILE
py -V
python -V
Get-ChildItem "$env:USERPROFILE\.claude\skills" -ErrorAction SilentlyContinue | Select-Object Name
```

파이썬 실행기를 `<PY>` 로 둔다. macOS 는 보통 `python3`, Windows 는 `py` 다.
**PowerShell 에 `head`, `grep`, `which` 는 없다.** Unix 명령을 섞어 쓰지 않는다.

파이썬이 없으면:

| OS | 명령 |
|---|---|
| macOS | 보통 이미 있다. 없으면 `brew install python@3.12` |
| Windows | `winget install --id Python.Python.3.12 -e` |

Windows 는 설치 후 **PowerShell 을 새로 열어야** PATH 가 잡힌다.

### 2단계. SSOT 찾기

정본 폴더 `{{SSOT_DRIVE}}` 를 찾는다. 그 안에 `50_도구상자` 가 있어야 맞는 것이다.

**macOS**

```bash
find ~/Library/CloudStorage -maxdepth 3 -type d -name "{{SSOT_DRIVE}}" 2>/dev/null
```

`ls -d .../GoogleDrive-*/...` 는 쓰지 않는다. zsh 는 glob 이 안 맞으면 오류를 낸다.

**Windows** : 구글 드라이브는 보통 `G:` 로 붙는다. 폴더명은 계정 언어에 따라
`공유 드라이브` 또는 `Shared drives` 다.

```powershell
Get-PSDrive -PSProvider FileSystem | ForEach-Object {
  foreach ($n in @('공유 드라이브','Shared drives')) {
    $p = Join-Path (Join-Path $_.Root $n) '{{SSOT_DRIVE}}'
    if (Test-Path $p) { $p }
  }
}
Get-ChildItem "$env:USERPROFILE\Google Drive" -Directory -ErrorAction SilentlyContinue |
  Select-Object FullName
```

### 3단계. 스킬 복사

SSOT `50_도구상자/10_스킬/minutes/` 전체를 사용자 스킬 폴더로 복사한다.

**macOS**

```bash
mkdir -p ~/.claude/skills
cp -R "<SSOT>/50_도구상자/10_스킬/minutes" ~/.claude/skills/
```

**Windows**

```powershell
New-Item -ItemType Directory -Force "$env:USERPROFILE\.claude\skills" | Out-Null
Copy-Item -Recurse -Force "<SSOT>\50_도구상자\10_스킬\minutes" "$env:USERPROFILE\.claude\skills\"
```

### 4단계. 의존성 설치

**ffmpeg** (필수. 음성 추출과 변환에 쓴다)

| OS | 명령 |
|---|---|
| macOS | `brew install ffmpeg` |
| Windows | `winget install --id Gyan.FFmpeg -e` |

Windows 에서 패키지 ID 를 생략하면(`winget install ffmpeg`) 검색 결과 선택을 요구하거나
엉뚱한 패키지가 깔린다. **`--id Gyan.FFmpeg -e` 를 그대로 쓴다.**
설치 후 **터미널을 새로 열어야** PATH 가 잡힌다.

**파이썬 패키지** (필수)

```bash
<PY> -m pip install --upgrade requests
```

`requests` 는 Groq 전송에 쓴다. 이것이 없으면 전사가 시작되지 않는다.

**faster-whisper** (선택. 외부로 내보내면 안 되는 회의용)

```bash
<PY> -m pip install faster-whisper
```

평소에는 필요 없다. 로컬 전사(`--offline`)를 쓸 사람만 깐다.
모델 2.9GB 를 첫 실행 때 내려받는다.

권한 오류가 나면 관리자 권한이 필요하다고 알리고 명령을 사람에게 보여준다.
**관리자 권한을 임의로 시도하지 않는다.**

### 5단계. 환경 점검 (사람 개입 없이 확인된다)

```bash
<PY> ~/.claude/skills/minutes/scripts/transcribe.py --doctor
```

Windows 는 경로를 `"$env:USERPROFILE\.claude\skills\minutes\scripts\transcribe.py"` 로 바꾼다.

OS, 파이썬 버전, ffmpeg, ffprobe, requests, Groq 키, faster-whisper 를 한 번에 점검하고
**부족한 것마다 고치는 명령을 같이 출력한다.** 전부 `OK` 가 나와야 다음으로 간다.

### 6단계. Groq 키

`--doctor` 가 `Groq 키: 없음` 이라고 하면 사용자에게 안내한다.

1. console.groq.com 에서 **본인 회사 이메일로** 가입 (신용카드 불필요)
2. API Keys >> Create API Key
3. 생성 직후 화면에서만 전체 키가 보인다. 그때 복사

**키는 각자 발급받아야 한다.** 무료 한도가 계정당 하루 8시간이라,
한 키를 나눠 쓰면 한도를 나눠 쓰고 그 키가 막히면 전원이 멈춘다.

받은 키를 저장한다. **대화창에 키를 붙여넣지 말고 터미널에서 직접 실행하게 한다.**

```bash
<PY> ~/.claude/skills/minutes/scripts/groq_setup.py gsk_받은키
```

저장 위치는 `~/.config/{{WORKSPACE_SLUG}}/groq.json` (Windows 는 `%USERPROFILE%\.config\{{WORKSPACE_SLUG}}\groq.json`) 이고,
저장 직후 실제 호출로 동작을 확인한다.

### 7단계. 동작 확인

스킬 폴더의 샘플로 한 번 돌린다.

```bash
<PY> ~/.claude/skills/minutes/scripts/transcribe.py \
     ~/.claude/skills/minutes/assets/샘플_한국어_시험음성.m4a \
     --out /tmp/minutes_test
```

전사 문장이 나오면 성공이다. 확인 후 `/tmp/minutes_test` 를 지운다.

Fathom 경로만 쓸 사람은 이 단계 대신 `~/.config/{{WORKSPACE_SLUG}}/fathom.json` 이 있는지만 본다.
없으면 연구기획사업부에 요청하도록 안내한다.

### 8단계. 마무리

**Claude Code 를 완전히 종료했다가 다시 켜라고 안내한다.**
스킬 목록은 세션 시작 때 읽으므로, 재시작해야 `/minutes` 가 잡힌다.
