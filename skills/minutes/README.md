# 회의록 자동화 (minutes)

회의 녹음을 넣으면 회의록 초안이 나옵니다. 이름과 과제명은 회사 정본과 대조해 고칩니다.

**버전 1.0.0 · 2026-09-29**
맥에서 검증했습니다. **윈도우는 아직 실사용 검증 전입니다.** 막히는 곳이 있으면 알려주세요.

---

## 먼저: 나는 무엇을 해야 하나

| 내가 하는 회의 | 할 일 | 걸리는 시간 |
|---|---|---|
| **온라인만** (Zoom · Meet · Teams) | 아래 「Fathom 연결」 3단계 | 약 5분 |
| **대면 회의도 녹음한다** | Fathom 연결 + 아래 「설치」 5단계 | 약 20분 |

**둘 다 한 번만 하면 됩니다.**

---

## 온라인 회의: Fathom 연결 (각자 본인 계정으로)

Fathom 은 온라인 회의에 자동으로 참석해 녹화하고 전사합니다.
**각자 본인 계정으로 가입하고 본인 것을 연결합니다.** 남의 계정을 같이 쓰지 않습니다.

### 1. 가입하고 회의 계정 연결

`fathom.video` 에서 **회사 이메일로** 가입합니다. 무료 플랜으로 충분합니다.
가입 후 본인 **Zoom 또는 Google Meet 계정을 연결**합니다.

### 2. Claude Code 에 붙이기 (터미널에서 한 번만)

```bash
claude mcp add fathom -- env -u NODE_OPTIONS npx -y mcp-remote@latest https://api.fathom.ai/mcp
```

맥·윈도우 같은 명령입니다.

### 3. 로그인

Claude Code 를 **완전히 종료했다 다시 켜면** 브라우저가 열립니다.
**본인 Fathom 계정으로 로그인**하면 끝입니다. API 키를 따로 저장할 필요가 없습니다.

연결 확인:

```bash
claude mcp list
```

`fathom` 이 `connected` 로 나오면 됩니다.

### 그다음부터

**아무것도 하지 않아도 됩니다.** 회의가 시작되면 Fathom 이 자동으로 들어와 녹화합니다.
회의가 끝나면 Claude Code 창에 이렇게 씁니다.

```
회의록 만들어줘. Fathom에서 오늘 [회의명] 가져와줘.
```

**Fathom 봇이 회의에 못 들어오는 경우가 있습니다.** 남이 연 방일 때 그렇습니다.
봇이 대기실에 갇히고, 호스트가 「참가자」 패널을 열어 승인해야 들어옵니다.
승인이 안 되면 **OBS로 녹화**하세요. `OBS_회의녹화.md`를 보시면 됩니다.

**맥 화면 기록(Cmd+Shift+5)은 쓰지 마세요.** 마이크만 잡혀서 상대 목소리가 통째로 사라집니다.
실제로 2026-09-22 회의에서 45분 녹화 중 상대 발언이 전부 유실됐습니다.

## 설치 (대면 녹음을 하는 사람만)

### 1. ffmpeg

| OS | 명령 |
|---|---|
| **Windows** (PowerShell) | `winget install --id Gyan.FFmpeg -e` |
| **Mac** (터미널) | `brew install ffmpeg` |

윈도우에서 `--id Gyan.FFmpeg -e`를 빼지 마세요. 그냥 `winget install ffmpeg`하면
목록 선택을 요구하거나 엉뚱한 게 깔립니다.

**설치 후 터미널을 껐다 다시 켜야** 인식됩니다.

### 2. 파이썬 패키지

| OS | 명령 |
|---|---|
| **Windows** | `py -m pip install requests` |
| **Mac** | `python3 -m pip install requests` |

파이썬이 없으면 먼저 설치합니다.
윈도우 `winget install --id Python.Python.3.12 -e` · 맥 `brew install python@3.12`

### 3. Groq 키 (본인 계정으로)

1. **console.groq.com** 에서 **회사 이메일로** 가입합니다. 신용카드는 묻지 않습니다
2. 왼쪽 **API Keys** → **Create API Key**
3. **생성 직후 화면에서만 전체 키가 보입니다.** 그때 복사하세요

**키는 각자 발급받아야 합니다.** 무료 한도가 계정당 하루 8시간인데,
한 사람 키를 여럿이 나눠 쓰면 그 8시간을 나눠 쓰게 되고, 그 키가 막히면 전원이 멈춥니다.

받은 키는 **대화창에 붙여넣지 말고** 터미널에서 직접 실행하세요. 대화 기록에 남지 않습니다.

```bash
# Mac
python3 ~/.claude/skills/minutes/scripts/groq_setup.py gsk_받은키

# Windows (PowerShell)
py "$env:USERPROFILE\.claude\skills\minutes\scripts\groq_setup.py" gsk_받은키
```

### 4. 스킬 설치

Claude Code 창에 이렇게 씁니다. 경로는 알아서 찾습니다.

```
{{SSOT_DRIVE}} 공유 드라이브에서 50_도구상자/10_스킬/minutes/설치.md 파일을
찾아서 읽고, 거기 적힌 순서대로 설치해줘.
내 OS와 구글 드라이브 경로는 네가 직접 확인해. 나한테 묻지 마.
```

끝나면 **Claude Code를 완전히 종료했다가 다시 켜세요.** 스킬 목록은 시작할 때 읽습니다.

### 5. 제대로 깔렸는지 확인

```bash
# Mac
python3 ~/.claude/skills/minutes/scripts/transcribe.py --doctor

# Windows
py "$env:USERPROFILE\.claude\skills\minutes\scripts\transcribe.py" --doctor
```

전부 `OK`면 끝입니다. `!!`가 있으면 **그 줄 아래에 고치는 명령이 같이 나옵니다.**

## 쓰는 법

Claude Code 창에 **녹음 파일을 끌어다 놓고** 이렇게 씁니다.

```
이거 회의록 만들어줘.
```

영상 파일이어도 됩니다. 음성만 알아서 뽑습니다. 1시간 회의가 **약 1분**입니다.

### 실행하면 한 번 묻습니다

기본은 녹음을 **Groq 서버로 보내서** 전사합니다. 그래서 실행 중에 확인을 묻습니다.

**외부 인사 발언, 환자 정보, 미공개 과제 내용이 있으면 「아니오」를 누르세요.**
이 컴퓨터 안에서만 처리하는 방식으로 다시 돌립니다. 대신 녹음 길이의 약 2배가 걸립니다.

### 그다음에 할 일은 한 번입니다

초안과 함께 **「모르겠는 것」 목록**이 나옵니다. 확정할 수 없어 빈칸으로 둔 항목입니다.
**아는 것만 채워주세요.** 채운 것이 정본이 됩니다.

확실하지 않은 것을 그럴듯하게 채우지 않는 것이 이 워크플로우의 원칙입니다.

## 막힐 때

| 증상 | 해결 |
|---|---|
| `ffmpeg를 찾을 수 없습니다` | 터미널을 껐다 다시 켜세요. 설치 후 새 창이 필요합니다 |
