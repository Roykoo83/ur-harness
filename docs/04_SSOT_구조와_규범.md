# 04 · 정본(SSOT) 구조와 규범

정본은 **구성원 전원이 같은 것을 보는 단일 지점**이다. 구조와 규칙을 함께 읽는다.

## 1. 폴더 구조

`ssot-template/` 에 빈 뼈대가 있다. 조직에 맞게 이름만 바꿔 쓴다.

```
정본 드라이브/
├─ CLAUDE.md               ← 진입점. AI 가 폴더를 열면 이것부터 읽는다
├─ AGENTS.md               ← 다른 클라이언트용 같은 내용
├─ 00_공통/
│  ├─ 10_조직/             명부
│  ├─ 20_일정/             캘린더 (자동)
│  └─ 50_온톨로지/         사람 · 조직 · 고객 · 과제
├─ <부서>/
│  ├─ 10_과제/             과제별 정본 ← 사람이 쓰는 주 공간
│  │  ├─ 0_제안/ 1_수행중/ 2_실주/ 3_종료·정산/ 4_인증·기타/
│  ├─ 00_부서정본/         주간보고 등
│  ├─ 40_커뮤니케이션/     메일 · 메신저 · 회의록 (메일·메신저는 자동)
│  └─ 50_대시보드/         (자동)
├─ 30_시스템/              설계 · 서비스 문서
├─ 50_도구상자/
│  ├─ 00_규범/             공통규약 · 쓰기구역표
│  ├─ 00_온보딩/           온보딩 · 지침 템플릿 · 환경조사
│  └─ 10_스킬/             SKILL.md
└─ _시스템/                색인 · 상태 · 보안 — 기계 전용
```

## 2. 과제 폴더 안

과제 하나가 생애주기를 따라 움직인다. **폴더를 옮기지 파일을 흩지 않는다.**

```
<과제명>/
├─ CLAUDE.md          이 과제의 맥락 (AI 가 먼저 읽는다)
├─ GOAL.md            목표와 지금 상태
├─ 수행/              진행 중 산출물
├─ 제출본/            대외 제출 확정본
├─ 90_작업로그/<이름>/ YYYY-MM-DD_<주제>.md
└─ _로컬/             외부에 내지 않는 원본 (필요할 때만)
```

## 3. 규범 — 네 가지

### ① 쓰는 주체는 경로마다 하나

| 구역 | 누가 쓰나 |
|---|---|
| 과제 폴더 · 부서정본 · 회의록 | **사람(의 AI)** |
| 메일 · 메신저 · 캘린더 · 대시보드 · `_시스템/` | **자동화만** |

섞으면 동기화가 충돌하고 사본이 생긴다. **자동화 구역은 읽기만 한다.**
고치고 싶으면 내 폴더로 복사해서 고친다.

### ② 「없다」고 말하기 전에 탐색 보고

```
신선도   보고 있는 자료가 언제 것인가
읽은 것  무엇을 열어 봤는가
핵심     찾은 사실
미발견   못 찾은 것 — 이 줄이 마지막이다
```

**「미발견」은 보고의 마지막 줄로만 쓴다.** 탐색 없이 "없다"고 하지 않는다.

### ③ 신선도를 먼저 본다

작업 전에 정본의 신선도 지표를 읽는다. 오래됐으면 **결론 내기 전에 사람에게 알린다.**
낡은 자료로 내린 결론은 틀린 줄도 모르고 퍼진다.

### ④ 되돌릴 수 있게 한다

- 삭제는 휴지통을 거친다
- 자동화는 자기가 만든 파일만 덮어쓴다
- 남의 파일은 지우지도 옮기지도 않는다. 확실하지 않으면 먼저 묻는다

## 4. 보안 등급

| | 뜻 |
|---|---|
| S0 | 공개 |
| S1 | 사내 공개 |
| S2 | 대외비 |
| S3 | 제한 |

**등급은 라벨이지 권한이 아니다.** 접근 통제는 드라이브 권한이 한다.
그리고 **개인 식별 + 금전이 결합된 문서는 정본에 올리지 않는다** — 원천에 두고 경로만 참조한다.

## 5. 파일을 찾을 때

폴더를 걸어 다니지 말고 `_시스템/색인/` 의 파일 목록을 검색한다.
색인이 멈춰 있으면(`색인_보류`) 그 사유를 먼저 본다 — **원본과 어긋나서 일부러 멈춘 것**이다.

## 6. 작업로그

```markdown
---
작업일: "YYYY-MM-DD"
담당: "<이름>"
---
# 무엇을 했나
## 신선도
## 읽은 것
## 핵심
## 미발견
```

한 일을 적는 것이 아니라 **다음 사람이 다시 찾지 않게** 적는다.
