# 09 · 윈도우 설치

> Windows 10/11 · Windows Server 2019+ 에 하네스를 올린다.
> Linux·macOS 는 `01_관리자_온보딩.md` 를 본다. **설정과 서비스 정의는 세 OS가 같다** —
> 다른 것은 설치 방법과 스케줄러뿐이다.

## 0. 무엇이 같고 무엇이 다른가

| | Linux | macOS | Windows |
|---|---|---|---|
| 설정 | `config/harness.yaml` | 같음 | 같음 |
| 서비스 정의 | `install/services.yaml` | 같음 | 같음 |
| 설치 점검 | `bootstrap.sh` | `bootstrap.sh` | **`bootstrap.ps1`** |
| 스케줄러 | systemd 사용자 유닛 | launchd | **작업 스케줄러** |
| 생성 명령 | `configure.py --units` | `--units` | **`configure.py --tasks`** |

`--all` 은 돌고 있는 OS 를 보고 알아서 고른다. 정의 파일은 하나다 —
OS 마다 정의를 따로 두면 한쪽만 고쳐지고 다른 쪽이 조용히 낡는다.

## 1. 받기

```powershell
git clone https://github.com/<계정>/ur-harness.git
cd ur-harness
powershell -ExecutionPolicy Bypass -File install\bootstrap.ps1 -Check
```

`-Check` 는 **아무것도 설치하지 않고** 무엇이 없는지만 알려준다.
확인한 뒤 `-Check` 를 빼고 다시 돌리면 동의를 받아 설치한다.

### 필요한 것

| | 왜 | 설치 |
|---|---|---|
| Python 3.10+ | 전부 | `winget install -e --id Python.Python.3.12` |
| git | 받기·갱신 | `winget install -e --id Git.Git` |
| rclone | **정본 읽기·쓰기** | `winget install -e --id Rclone.Rclone` |
| ffmpeg | 회의 전사 (선택) | `winget install -e --id Gyan.FFmpeg` |
| Node.js | 다이어그램 (선택) | `winget install -e --id OpenJS.NodeJS.LTS` |
| cloudflared | 봇 수신 (선택) | [공식 배포본](https://github.com/cloudflare/cloudflared/releases) |

> Python 설치 때 **"Add python.exe to PATH"** 를 반드시 체크한다.
> 체크하지 않으면 예약 작업이 파이썬을 못 찾아 조용히 실패한다.

> `winget` 설치 직후에는 PATH 가 현재 창에 반영되지 않는다.
> **PowerShell 을 닫고 다시 연 뒤** 점검을 다시 돌린다.

## 2. 설정

```powershell
copy config\harness.example.yaml config\harness.yaml
notepad config\harness.yaml
```

채울 것은 `01_관리자_온보딩.md` §2 와 같다. 윈도우에서만 추가로 볼 것:

```yaml
install:
  python_windows: ""      # 비우면 PATH 의 pythonw.exe. 여러 버전이 깔려 있으면 전체 경로로 고정한다
                          # 예: C:\Users\<사용자>\AppData\Local\Programs\Python\Python312\pythonw.exe
```

`pythonw.exe` 는 콘솔 창을 띄우지 않는다. 예약 작업이 15분마다 검은 창을 띄우면
쓰는 사람이 작업을 꺼 버린다 — 그래서 기본값이다.

## 3. 드라이브 원격

```powershell
rclone config
```

`SSOT_ro`(읽기) · `SSOT_rw`(쓰기) 두 개를 만든다. 절차는 `01_관리자_온보딩.md` §3 과 같다.
확인:

```powershell
rclone lsd SSOT_ro:
```

## 4. 빌드와 예약 작업

```powershell
python install\configure.py --check      # 설정이 다 찼는가
python install\configure.py --all        # 빌드 + 작업 XML 생성
```

`--all` 은 윈도우에서 `--tasks` 를 고른다. `install\schtasks\UR-*.xml` 이 만들어진다.
등록은 **관리자 권한이 필요 없다**:

```powershell
Get-ChildItem install\schtasks\UR-*.xml | ForEach-Object {
  schtasks /Create /XML $_.FullName /TN "UR Harness\$($_.BaseName)" /F }
```

확인:

```powershell
schtasks /Query /TN "UR Harness\UR-watchdog" /V /FO LIST
```

### 로그아웃해도 돌게 하기

기본값은 **로그온한 동안만** 돈다. 서버라면 이것으로는 부족하다.

1. `taskschd.msc` 를 연다 → `UR Harness` 폴더
2. 각 작업 → 속성 → 일반 → **"사용자의 로그온 여부에 관계없이 실행"**
3. 계정 암호를 한 번 묻는다

> 이것을 켜지 않으면 **화면을 잠그고 퇴근한 뒤 아무것도 돌지 않는다.**
> 다음 날 아침에는 "어제 하루가 통째로 비어 있다"는 모습으로 나타난다.

## 6. 윈도우에서 다른 점 (알고 있어야 할 것)

**경로 길이** — 기본 260자 제한이 있다. SSOT 의 한글 과제 폴더는 깊어질 수 있다.
미리 풀어 둔다 (관리자 PowerShell 1회):

```powershell
New-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Control\FileSystem" `
  -Name LongPathsEnabled -Value 1 -PropertyType DWORD -Force
```

**줄바꿈** — `.gitattributes` 가 없는 저장소에서 git 이 CRLF 로 바꾸면 파이썬은
괜찮지만 일부 설정 파일이 어긋난다. 받을 때 한 번:

```powershell
git config --global core.autocrlf input
```

**한글 인코딩** — 콘솔이 CP949 면 로그의 한글이 깨진다. 작업 XML 은 파일로 로그를
남기므로 영향이 없지만, 손으로 돌릴 때는 한 번 설정한다:

```powershell
$env:PYTHONUTF8 = "1"      # 영구히: setx PYTHONUTF8 1
```

**마운트 동기화** — `mount-resync` 서비스는 macOS 전용이라 윈도우에서는 만들어지지
않는다. 윈도우의 Google Drive 도 같은 종류의 지연이 있지만 진단 방법이 다르다.
**마운트는 읽기·백업 용도로만 쓰고, 쓰기는 rclone 으로 한다** — 이 원칙은 세 OS 가 같다.

## 7. 멈추기·되돌리기

```powershell
# 전부 멈춤
Get-ScheduledTask -TaskPath "\UR Harness\" | Disable-ScheduledTask

# 하나만
Disable-ScheduledTask -TaskName "UR-watchdog" -TaskPath "\UR Harness\"

# 완전히 제거
Get-ScheduledTask -TaskPath "\UR Harness\" | Unregister-ScheduledTask -Confirm:$false
```

작업을 지워도 `config/harness.yaml` 과 작업공간의 데이터는 남는다.
이관 때 이전 담당자 기계에서 **먼저 멈추고** 새 기계에서 올린다 —
둘이 동시에 돌면 같은 정본에 둘이 쓴다. `00_이관_체크리스트.md` 를 따른다.
