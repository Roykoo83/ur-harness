# 05 · 업무 매뉴얼 — 정본으로 실제 일하기

사업계획서 · 예산 · 회의록 · 주간보고를 정본 위에서 만드는 방법.

## 공통 — 어떤 작업이든 이 순서

```
1 과제를 연다        "과제 시작" → 어디까지 했는지 브리핑을 받는다
2 신선도를 본다      자료가 언제 것인지 먼저 확인
3 읽을 것을 정한다   과제 CLAUDE.md · GOAL.md · 관련 메일·회의록
4 만든다            초안은 대화에, 확정본만 정본 폴더에
5 작업로그를 남긴다
```

**초안을 정본에 올리지 않는다.** 확정된 것만 올린다. 그래야 "무엇이 최신인가"가 흔들리지 않는다.

---

## 1. 사업계획서 · 제안서

### 먼저 모으는 것

| 무엇 | 어디서 |
|---|---|
| 공고문 · 서식 | 과제 폴더 `수행/` |
| 기관·고객 정보 | 온톨로지 `조직/` |
| 참여 인력 | 온톨로지 `사람/` · 명부 |
| 과거 유사 과제 | `10_과제/3_종료·정산/` |
| 관련 교신 | `40_커뮤니케이션/메일/` |

### 쓰는 법

AI에게 과제 폴더를 열게 한 뒤 공고문과 서식을 읽히고, **과거 유사 과제의 제출본을
근거로 삼아** 초안을 만든다. 처음부터 쓰지 않는다 — 조직이 이미 쓴 표현과 실적이 있다.

- 수치(사업비·인력·기간)는 **반드시 출처를 함께** 적는다
- 기관명·인명은 온톨로지 표기를 따른다. 표기가 갈리면 온톨로지를 먼저 고친다
- 확정본은 `제출본/` 에, 과정은 `수행/` 에

### 자주 나는 실수

| | |
|---|---|
| 과거 과제 표현을 그대로 복사 | 공고 요건이 다르면 감점. **요건 대조표를 먼저 만든다** |
| 인력 정보를 손으로 적음 | 온톨로지에서 가져온다. 직책·소속이 바뀌어 있을 수 있다 |
| 초안을 제출본 폴더에 | `수행/` 에 두고 확정 때 옮긴다 |

## 2. 예산 · 정산

### 원장이 정본이다

예산은 **원장(대장)**이 정본이고 문서는 그 파생물이다. 원장을 고치고 문서를 다시 만든다.
반대로 하면 둘이 어긋난다.

```
편성 → 집행 → 잔액
  각 항목에 근거(증빙·결재번호)를 붙인다
```

### 하는 법

1. 원장을 연다 (`agents/budget/` 가 동기화한 데이터셋)
2. 집행 내역을 **결재 알림과 대조**한다 — 메일 정본에 결재 기록이 남아 있다
3. 차이가 나면 **원장을 고치고** 보고서를 다시 생성한다
4. 잔액·집행률은 계산 결과를 그대로 쓴다. 손으로 적지 않는다

### 주의

- **개인 식별 + 금전이 결합된 문서는 정본에 올리지 않는다.** 원천에 두고 경로만 참조
- 인건비 집행 내역은 과제 정산의 근거이므로 **기록 자체는 남긴다** — 올리는 위치만 가린다

## 3. 회의록

### 두 경로

| 회의 | 방법 |
|---|---|
| 온라인 | 전사 서비스가 자동 녹취 → 가져오기 |
| 대면 | 휴대폰 녹음 파일을 건네면 전사 |

```
전사 확보 → 용어 교정 → 1차 초안 → 사람이 수정 → 확정본
```

### 교정이 핵심이다

**자동 전사는 사람 이름과 숫자를 틀린다.** 들린 대로 두면 틀린 이름이 사실처럼 굳는다.
그래서 온톨로지의 인물·조직·과제 표기로 교정하는 단계가 들어 있다.

- 교정 후 **사람이 반드시 한 번 읽는다**
- 전사 품질 경고(종료 코드 2)가 나오면 **확정하지 않는다**
- 민감한 회의는 로컬 전사 경로를 쓴다

### 확정본에 담는 것

```markdown
일시 · 장소 · 참석자(온톨로지 표기)
## 결정
## 할 일   (누가 · 언제까지)
## 보류
## 원문   (전사 파일 경로)
```

**결정과 할 일을 분리한다.** 할 일에 담당과 기한이 없으면 결정이 아니다.

## 4. 주간보고

### 자동으로 모이는 것

| | |
|---|---|
| 지난 주 메일·메신저 | 정본에서 자동 |
| 과제 상태 변화 | 원장에서 자동 |
| 일정 | 캘린더에서 자동 |

### 사람이 쓰는 것

- **판단** — 무엇이 문제이고 무엇이 필요한가
- **다음 주 계획**

자동으로 모인 것을 근거로 판단만 쓴다. 사실 나열을 손으로 하지 않는다.

---

## 5. 막혔을 때

| 증상 | 조치 |
|---|---|
| 필요한 자료가 정본에 없다 | 판정 대장을 본다 — 업무 무관으로 걸러졌을 수 있다. 원천에는 남아 있다 |
| 기관명 표기가 문서마다 다르다 | 온톨로지를 먼저 통일하고 문서를 다시 만든다 |
| 숫자가 문서마다 다르다 | 원장을 정본으로 삼고 파생물을 재생성한다 |
| AI가 과거 자료를 못 찾는다 | 신선도를 확인한다. 색인이 멈춰 있을 수 있다 |
